# 概要
東方のスコアアタックをサポートするツールです．<br>
現在の対応作品は以下の通りです．

- 東方妖々夢 〜 Perfect Cherry Blossom.

[tableofcoontent]

# できること
プレイしている自機，プレイしている難易度，ステージ，場所を自動で判別し，およそ6フレーム毎に桜分子，桜分母，桜+を記録します．

# 推奨環境
- python==3.9.13
- pymem==1.14.0

# 使用方法
下記のコマンドを実行してください．

> python main.py

コンソール上に現在読み取っている値が出力されます．<br>
また実行したmain.pyと同じフォルダにlog.csvファイルとして記録が保存されます．

### <u>**注意**</u>
ポーズ中もログを保存し続けるので，残り容量に不安がある人は定期的に動作をストップしてください．
